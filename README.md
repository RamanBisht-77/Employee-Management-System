🚀 EMS (Employee Management System)

📌 Project Description

This is a frontend-based Employee Management System built using React.
It allows admin to assign tasks and employees to manage and update their tasks.

---

✨ Features

- 🔐 Login system (Admin & Employee)
- 📊 Admin dashboard (view all employees & tasks)
- ✅ Assign tasks to employees
- 👨‍💻 Employee dashboard (view & update tasks)
- 🔄 Real-time task status update
- 💾 Data stored using LocalStorage

---

🛠️ Tech Stack

- React.js
- Context API (State Management)
- Tailwind CSS
- LocalStorage

---

📂 Folder Structure

- "/Components" → UI Components
- "/Context" → Global state (AuthProvider)
- "/Utils" → LocalStorage logic

---

▶️ How to Run Project

npm install
npm run dev
